ログインのファイルの関係

PR #24 で書いたファイルが、どうつながっているかを図にします。流れそのもの(誰が誰に何を頼むか)は vue-google-login.html の図2・図3 にあります。このページは、それを「ファイル」の目で見直したものです。

先に結論です。ファイルどうしのつながりは、3種類あります。

  • コードの読み込み:どのファイルが、どのファイルの道具を使うか(1章)
  • 設定値の通り道:.env に書いた値が、どのファイルに届くか(2章)
  • リクエストの通り道:画面から Rails まで、どのファイルを通るか(3章)

1コードの読み込み(Vue)

上にあるものが道具を作り、下のファイルへ渡します。矢印は、道具が渡る向き(上から下)です。矢印の先のファイルは、その道具を import して受け取り、使います。線の横の小さな文字が、渡る道具の名前です。

  1. Firebase の SDK が、firebase.ts に initializeApp と getAuth を渡す。firebase.ts は、それでログインの窓口(auth)を1つ作る
  2. firebase.ts が、その1つの auth を、stores/auth.ts と api/client.ts の両方に渡す
  3. stores/auth.ts は、Firebase の SDK から signInWithPopup、onAuthStateChanged などの道具を、Pinia から defineStore を受け取り、ストアを作る
  4. stores/auth.ts がストア(useAuthStore)を、api/client.ts が Rails を呼ぶ関数(apiFetch)を、App.vue に渡す
  5. App.vue と Pinia(createPinia)が main.ts に渡り、main.ts がアプリを起動する

2設定値の通り道

Firebase のプロジェクトの設定値は、オーナーが .env に書いたところから、Vue と Rails の両方に届きます。

  1. オーナーが、.env.example を写して .env を作り、Firebase のコンソールで見た4つの値を書く
  2. compose.yaml(Docker Compose)が、.env を読み、web と api のコンテナの環境変数にする
  3. 上の道:Vite が VITE_ で始まる値を import.meta.env に出し、firebase.ts が読んで SDK に渡す。env.d.ts は、その名前の書き間違いを型で見つける
  4. 下の道:config/application.rb が ENV["FIREBASE_PROJECT_ID"] を設定に入れ、トークンを検証するクラスが、ID トークンの宛先のプロジェクトと比べる(Issue #8)

3リクエストの通り道

ログインしたあと、画面が会員の id を受け取るまでに通るファイルです。

App.vue と api/client.ts の間の矢印は、図1 と図3 で向きが逆です。図1 は道具(apiFetch という関数)が渡る向きで、アプリを開いたときに1回だけ、api/client.ts から App.vue へ渡ります。図3 は頼みごと(リクエスト)が進む向きで、App.vue が受け取った apiFetch を使うたびに、App.vue から api/client.ts へ進みます。電話機を受け取るのが図1、その電話機で電話をかけるのが図3 です。

  1. App.vue が、ストアの user が会員に変わったのに気づき、apiFetch('/api/me') を呼ぶ
  2. api/client.ts が、SDK から ID トークンをもらって Authorization の欄に入れ、ブラウザから localhost:5173/api/me に送る
  3. Vite の開発サーバーが、vite.config.ts の設定どおり、/api で始まるリクエストを Rails(api:3000)に転送する
  4. me_controller.rb が、before_action で firebase_authenticatable.rb の確認を先に動かす
  5. firebase_authenticatable.rb が、Authorization の欄から ID トークンを取り出し、firebase_id_token_verifier.rb に確かめさせる(verify!)
  6. firebase_id_token_verifier.rb が、Google から公開鍵を取り(ここで net/http を使う)、署名と宛先を確かめる
  7. firebase_authenticatable.rb が会員を特定し(初めてなら作り)、me_controller.rb が会員の id を JSON で返す
  8. App.vue が、受け取った id を「会員 ID:1」として画面に出す
