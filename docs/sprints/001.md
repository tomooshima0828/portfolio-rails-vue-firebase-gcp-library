## ふりかえり(KPT)

### Keep(続けること)

- 仕様書 → テスト → 実装の順を守れた。何ができれば終わりかが、実装の前に決まっていた
- 迷った判断を ADR に残した(0002 ローカル開発は Docker、0003 CI の作り方)
- 1ファイルずつ説明を受けてから書くので、Rails と CI の中身を理解したまま進められた

### Problem(困ったこと)

- インフルエンザで約1週間休み、その間は進まなかった。一人で進めているので、休むとすべてが止まる
- 5ポイントの #8 を途中で足したが、休んだこともあり、期間内に終わらなかった
- 休み明けに計画を見直さず、スプリントの終わりの記録もしなかった。次のスプリントの計画も、ボードのスプリント欄も空のまま進めた

### Try(次に試すこと)

- 休んで止まったときは、復帰した日にボードを見直し、持ち越す Issue をその時点で決める
- スプリントの終わりと始まりの記録を、その週の最初の作業にする
- Issue に着手してカードを In Progress に移すとき、スプリント欄も同時に設定する
- 5ポイントの Issue は、着手前に分けられないか検討する
